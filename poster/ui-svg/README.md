# UI SVG Exports

Poster-ready SVG recreations of the current TFT UI states.

Generated by `tools/generate_ui_svgs.py`.

Each SVG uses `viewBox="0 24 160 80"` to match the TFT visible area.
Colors represent the intended firmware UI colors without red/blue compensation.

- `01-main-stopped.svg`: Main Stopped
- `02-main-playing.svg`: Main Playing
- `03-track-menu.svg`: Track Menu
- `04-master-volume.svg`: Master Volume
- `05-track-volume.svg`: Track Volume
- `06-bpm.svg`: BPM
- `07-bars.svg`: Bars
- `08-osc-menu.svg`: OSC Menu
- `09-record-armed.svg`: Record Armed
- `10-recording.svg`: Recording
